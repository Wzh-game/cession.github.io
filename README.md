# 梦幻西游 · 1.1 单机版

一个基于 HTML、CSS 和 JavaScript 的浏览器单机 RPG 游戏项目。游戏入口为 `index.html`，可通过 GitHub Pages 在线访问。

## 在线体验

- **游戏地址：** https://wzh131213-dev.github.io/cession.github.io/
- **GitHub 仓库：** https://github.com/wzh131213-dev/cession.github.io
- **当前开发分支：** `add-save-import-export`

## 当前版本内容

### 门派与技能

- 游戏包含多个可选择门派，并加入了全新门派 **老牧私**。
- 支持门派切换；切换会重置角色等级、经验、宠物及宠物仓库，保留银两、背包、任务、地图进度和外观。
- 战斗中不能切换门派。
- 老牧私拥有四项专属技能：

| 技能 | 解锁等级 | 消耗 | 效果 |
|---|---:|---:|---|
| 滚木 | Lv.1 | 10 MP | 自身获得 60 秒无敌效果，冷却 60 分钟 |
| 西格玛滚木拳 | Lv.3 | 67 MP | 对目标造成 67 点伤害 |
| 滚木之眼 | Lv.5 | 20 MP | 造成上一回合玩家受到伤害总和的 2 倍伤害 |
| 浮木消失术 | Lv.10 | 100 MP | 使一名敌人从当前战斗中消失 |

### Boss 与地图

- 地图中设置了五个 Boss 挑战点：
  - 长安镇城妖将
  - 碧波树皇
  - 黄沙魔君
  - 极寒雪魔
  - 熔岩炎帝
- Boss 使用独立像素风格图案进行区分。
- 地图支持玩家位置标记、坐标 HUD 和地图比例显示。
- 首次击败对应 Boss 可获得专属功法；重复击败不会重复获得该首杀功法。

### 功法修炼

- 新增独立的「功法」入口，可查看和修炼已获得的功法。
- 功法按对应 Boss 难度递增，所需在线修炼时间逐步增加：

| 功法 | 所需在线时间 | 主要效果 |
|---|---:|---|
| 金刚护体诀 | 10 分钟 | HP 上限 +80，防御 +8 |
| 青木长生经 | 30 分钟 | HP 上限 +180 |
| 流沙裂岳功 | 60 分钟 | 攻击 +18，速度 +5 |
| 玄冰心法 | 120 分钟 | 防御 +25，MP 上限 +100 |
| 九阳焚天诀 | 240 分钟 | 攻击 +40，法术 +35，HP 上限 +300 |

- 修炼成功率为 50%；失败会消耗本次使用的功法。
- 只有游戏页面处于前台时才累计在线修炼时间；切到后台或离开页面时不累计。
- 修炼进度、功法和完成状态会保存。

### 存档与界面

- 提供游戏存档相关功能，包括保存以及导入、导出入口。
- 底部功能栏新增「功法」入口。
- 地图打开时隐藏坐标 HUD，关闭地图后恢复显示。

## 运行方式

### 在线运行

使用上方 GitHub Pages 地址即可在浏览器中打开游戏。

### 本地运行

1. 下载或克隆本仓库。
2. 打开项目中的 `index.html`。
3. 建议使用较新的 Chrome、Safari 或 Edge 浏览器。

项目为浏览器端单机游戏；具体功能是否可用取决于浏览器对页面脚本和本地存储的支持情况。
